# 내 손안의 마을 지도: 우리 지역 문화유산 탐험대 제작 설계서

작성일: 2026-04-30
대상: 3-4학년군 사회
범위: 경상북도 지도 기반 문화유산 탐험 웹앱 MVP 설계

## 1. 수업 목적

이 앱은 학생들이 경상북도 지도를 보며 우리 지역의 위치와 지리 정보를 탐색하고, 지도 위 문화유산 핀을 눌러 문화유산의 유형, 위치, 시대, 가치를 조사하는 대화형 웹 지도입니다. 학생은 기본으로 제공된 문화유산을 살펴본 뒤, 직접 조사한 문화유산을 지도에 새 핀으로 추가하며 "우리 지역 문화유산 탐험대" 활동을 완성합니다.

연계 성취기준은 다음과 같습니다.

- [4사05-02] 지도에서 우리 지역의 위치를 파악하고, 우리 지역의 지리 정보를 탐색한다.
- [4사06-01] 지역의 문화유산을 통해 문화유산의 의미와 유형을 알아보고, 문화유산의 가치를 탐색한다.

다중 성취기준 연계는 지도 읽기와 문화유산 탐구를 한 활동 안에 묶는 데 있습니다. 학생은 "문화유산이 어디에 있는지"를 지도에서 먼저 확인하고, "그 장소가 왜 중요한지"를 팝업과 기록장에 정리합니다.

## 2. 핵심 사용자와 사용 장면

주 사용자: 초등학교 3-4학년 학생

보조 사용자: 사회 수업을 운영하는 담임교사

수업 장면:

- 교사는 전자칠판이나 태블릿으로 경상북도 지도를 띄웁니다.
- 학생은 경북 지도에서 마커를 눌러 문화유산 정보를 확인합니다.
- 학생은 "위치 찾기", "문화유산 유형 찾기", "가치 한 문장 쓰기" 미션을 해결합니다.
- 확장 활동에서는 학생이 자신이 사는 시군의 문화유산을 조사해 새 핀을 추가합니다.

성공 기준:

- 학생이 경상북도 안에서 최소 3개 문화유산의 위치를 설명할 수 있습니다.
- 학생이 문화유산의 유형을 건축, 마을, 과학유산, 무덤, 서원 등으로 구분할 수 있습니다.
- 학생이 한 문화유산의 가치를 자신의 말로 1문장 이상 기록할 수 있습니다.
- 앱은 모바일, 태블릿, 교실 PC에서 지도, 마커, 팝업, 기록 기능이 안정적으로 동작합니다.

## 3. 설계 접근안

### 접근안 A: 정적 경북 지도 이미지 + 절대 좌표 마커

경상북도 지도 이미지를 화면 배경으로 놓고, 마커를 퍼센트 좌표로 배치합니다. 구현이 가장 단순하고 "바이브 코딩" 프롬프트와 잘 맞습니다. 다만 지도 비율이 달라질 때 마커 위치가 어긋나지 않도록 지도 컨테이너의 비율을 고정해야 합니다.

### 접근안 B: 경북 SVG 지도 + 마커 레이어

경상북도 행정구역 SVG를 앱의 지도 배경으로 사용하고, 그 위에 마커 버튼을 올립니다. 추천안입니다. 지도 이미지는 정적이지만 확대해도 선명하고, 시군 경계나 지역명을 표시하기 쉽습니다. 외부 지도 API 키가 필요 없어서 학교 환경과 GitHub Pages 배포에도 안정적입니다.

### 접근안 C: Leaflet 또는 VWorld 기반 실제 지도

실제 지도 확대, 이동, 타일 로딩을 사용할 수 있습니다. 하지만 API 키, 네트워크, 지도 저작권 표기, 초등학생에게 과도한 조작 복잡도가 생깁니다. 첫 버전에서는 제외하고, 향후 "우리 학교 주변 탐방" 기능이 필요할 때 검토합니다.

최종 추천: 접근안 B를 사용합니다. 사용자 요구인 "경상북도 지도 배경, 클릭 가능한 핀, 중앙 팝업"을 만족하면서도 수업용 배포와 유지보수가 쉽습니다.

구현 변경 기록: 실제 지도 사용 요청에 따라 MVP 구현은 접근안 C의 복잡한 API 키 방식이 아니라, Leaflet + OpenStreetMap 타일을 사용합니다. OpenStreetMap은 ODbL 기반 오픈 지도 데이터이며, 앱 화면에 `OpenStreetMap contributors` 출처와 라이선스 링크를 표시합니다.

## 4. 첫 화면 구조

첫 화면은 앱 소개 페이지가 아니라 바로 사용할 수 있는 지도 탐험 화면입니다.

레이아웃:

- 상단 바: 앱 이름, 학습 미션 진행률, 초기화 버튼
- 왼쪽 또는 상단 필터: 전체, 경주, 안동, 영주, 고령, 내가 추가한 핀
- 중앙: 경상북도 SVG 지도
- 지도 위: 문화유산 마커 버튼
- 하단 미션 패널: "오늘의 탐험 미션" 3개
- 모달: 마커 클릭 시 문화유산 이름, 사진, 위치, 유형, 시대, 설명, 학생 기록 입력란 표시

디자인 톤:

- 초등 사회 수업에 맞는 또렷한 지도 중심 UI
- 과도한 장식보다 지역명, 핀, 사진이 잘 보이는 구성
- 색상은 지도 배경의 연녹색, 강/바다의 청록색, 문화유산 핀의 주황색, 학생 추가 핀의 보라색을 함께 사용
- 버튼과 마커는 손가락 터치 기준으로 최소 44px 이상

## 6. 학생 상호작용

### 6.1 문화유산 핀 탐험

학생이 지도 위 핀을 누르면 중앙 모달이 열립니다.

모달 내용:

- 문화유산 이름
- 지역명과 지도 위치
- 유형과 시대
- 사진 또는 일러스트
- 3-4학년 수준의 짧은 설명
- "이 문화유산이 소중한 까닭" 기록 칸
- "탐험 완료" 버튼

기록 예시 문장:

- "경주 불국사는 통일신라 사람들이 만든 절이라서 신라의 문화를 알 수 있습니다."
- "하회마을은 사람들이 강 주변에 마을을 이루고 살았던 모습을 보여줍니다."

### 6.2 오늘의 탐험 미션

기본 미션:

- 경북 남쪽에 있는 문화유산 1개 찾기
- 마을이나 서원 문화유산 1개 찾기
- 내가 가장 보존하고 싶은 문화유산을 고르고 까닭 쓰기

미션 완료 상태는 로컬 저장소에 저장합니다. 새로고침해도 같은 브라우저에서는 이어서 활동할 수 있습니다.

### 6.3 나만의 문화유산 핀 추가

학생은 "내 핀 추가" 버튼을 눌러 직접 조사한 문화유산을 등록합니다.

입력 항목:

- 문화유산 이름
- 시군 선택
- 지도 위 위치 선택
- 유형 선택
- 한 줄 설명
- 내가 생각한 가치

개인정보 보호를 위해 학생 이름, 주소, 실제 위치 추적은 받지 않습니다. 사진 업로드는 첫 버전에서 제외하고, 교사가 허용한 이미지 URL 또는 기본 아이콘을 사용합니다.

## 7. 교사용 기능

교사용 기능은 2차 확장에서 별도 로그인 없이 화면 안의 "교사용 보기" 접이식 패널로 제공합니다. 1차 MVP에서는 학생 탐험 화면을 먼저 완성하고, 같은 내용을 간단한 문서나 README로 안내합니다.

내용:

- 수업 목표
- 40분 수업 흐름
- 기본 문화유산 출처
- 학생 기록 활동 안내
- 확장 질문

40분 수업 흐름:

| 단계 | 시간 | 활동 |
| --- | --- | --- |
| 도입 | 5분 | 경상북도 위치 확인, 오늘의 탐험 미션 안내 |
| 탐색 | 12분 | 기본 핀 3개 이상 눌러 위치와 유형 확인 |
| 조사 | 13분 | 관심 문화유산 하나를 골라 가치 문장 작성 |
| 확장 | 7분 | 자기 지역 문화유산 핀 추가 |
| 정리 | 3분 | 친구가 추가한 핀을 보고 알게 된 점 공유 |

## 8. 화면 구성 요소

권장 컴포넌트:

- `AppShell`: 전체 앱 구조와 상태 조합
- `GyeongbukMap`: 경북 지도 SVG와 마커 레이어
- `MapMarker`: 문화유산 핀 버튼
- `SiteModal`: 문화유산 정보 팝업
- `MissionPanel`: 오늘의 탐험 미션과 진행률
- `HeritageFilter`: 지역과 유형 필터
- `StudentNotebook`: 학생 기록 입력과 저장
- `AddPinDialog`: 학생 문화유산 핀 추가
- `TeacherGuidePanel`: 수업 운영 안내

상태 흐름:

1. 앱 시작 시 기본 문화유산 데이터와 로컬 저장 기록을 불러옵니다.
2. 학생이 마커를 누르면 `selectedSiteId`가 바뀌고 모달이 열립니다.
3. 학생이 기록을 저장하면 `StudentNote`가 로컬 저장소에 반영됩니다.
4. "탐험 완료"를 누르면 해당 문화유산의 완료 상태와 미션 진행률이 갱신됩니다.
5. 학생 추가 핀은 `CustomPin`으로 저장되고 지도 위 별도 색상 마커로 표시됩니다.

## 9. 데이터와 저장소

백엔드는 사용하지 않습니다. 첫 버전은 브라우저 로컬 저장소만 사용합니다.

저장 데이터:

```ts
type StudentNote = {
  siteId: string;
  valueSentence: string;
  question: string;
  updatedAt: string;
};

type CustomPin = {
  id: string;
  title: string;
  city: string;
  category: string;
  latitude: number;
  longitude: number;
  description: string;
  valueSentence: string;
  createdAt: string;
};
```

로컬 저장 키:

- `localHeritageMap.notes.v1`
- `localHeritageMap.customPins.v1`
- `localHeritageMap.completed.v1`

데이터 초기화 버튼은 학생 기록, 추가 핀, 완료 상태를 모두 지웁니다. 누르기 전 확인 대화상자를 띄웁니다.

## 10. 지도와 자료 출처 정책

지도:

- MVP 구현은 Leaflet 지도 위에 OpenStreetMap 표준 타일을 배경 지도로 사용합니다.
- OpenStreetMap 데이터는 ODbL 기반 오픈 데이터이므로, 앱 화면에 `OpenStreetMap contributors` 출처와 라이선스 링크를 표시합니다.
- 지도 타일은 네트워크가 필요합니다. 학교 네트워크에서 외부 타일 로딩이 막히는 경우를 대비해, 이후 버전에서는 OSM 기반 오프라인용 정적 이미지나 자체 타일 호스팅을 검토합니다.
- 문화유산 위치는 Nominatim/OpenStreetMap 검색 결과와 국가유산포털 소재지 정보를 대조해 위도/경도 좌표로 저장합니다.

문화유산:

- 기본 정보는 국가유산청 국가유산포털을 기준으로 합니다.
- 앱 본문 설명은 3-4학년 수준으로 재작성한 요약문을 사용합니다.
- 공식 사진을 직접 앱에 포함할 때는 국가유산포털 이미지별 이용 조건을 확인합니다.
- 이용 조건이 불명확하면 공식 사진을 앱에 복사하지 않고, 직접 제작한 수업용 일러스트 또는 공공누리 조건이 확인된 이미지만 사용합니다.

## 11. 접근성 요구사항

- 모든 마커는 `<button>`으로 구현하고 `aria-label`에 문화유산 이름과 지역을 넣습니다.
- 모달은 열릴 때 제목으로 초점이 이동하고, 닫으면 누른 마커로 초점이 돌아갑니다.
- ESC 키와 닫기 버튼으로 모달을 닫을 수 있습니다.
- 마커 선택, 기록 저장, 미션 완료는 `role="status"` 또는 `aria-live` 영역으로 알려줍니다.
- 색상만으로 유형을 구분하지 않고 아이콘과 텍스트를 함께 사용합니다.
- 모바일에서 지도와 모달 텍스트가 겹치지 않도록 모달은 하단 시트 형태로 바뀝니다.

## 12. 반응형 설계

데스크톱:

- 지도는 화면 중앙의 넓은 영역을 차지합니다.
- 미션 패널은 오른쪽 또는 하단에 고정합니다.
- 모달은 화면 중앙에 표시합니다.

태블릿:

- 지도는 상단, 미션 패널은 하단으로 배치합니다.
- 필터는 가로 스크롤 가능한 세그먼트 버튼으로 표시합니다.

모바일:

- 지도는 세로 화면에서도 전체 경북 윤곽이 보이도록 `aspect-ratio`를 유지합니다.
- 모달은 하단 시트로 표시합니다.
- 긴 설명은 2-3문장으로 제한하고, 학생 기록 입력칸은 접었다 펼칠 수 있게 합니다.

## 14. 테스트 계획

단위 테스트:

- 기본 문화유산 데이터가 id, 이름, 지역, 좌표, 출처를 모두 가지고 있는지 확인
- 퍼센트 좌표가 0-100 범위 안에 있는지 확인
- 로컬 저장소 저장, 불러오기, 초기화 동작 확인

상호작용 테스트:

- 마커를 클릭하면 해당 문화유산 모달이 열립니다.
- 기록을 입력하고 저장하면 새로고침 후에도 남습니다.
- "탐험 완료"를 누르면 진행률이 올라갑니다.
- 필터를 누르면 해당 지역 또는 유형의 마커만 보입니다.
- 학생 추가 핀을 만들면 지도에 새 마커가 표시됩니다.

접근성 테스트:

- 키보드만으로 마커 탐색, 모달 닫기, 기록 저장이 가능합니다.
- 모달 초점 이동과 복귀가 동작합니다.
- 저장 완료 메시지가 스크린리더용 상태 영역에 반영됩니다.

시각 검증:

- 데스크톱, 태블릿, 모바일 크기에서 지도와 마커가 어긋나지 않습니다.
- 경북 지도 윤곽, 지역명, 마커가 서로 겹치지 않습니다.
- 모달 사진과 텍스트가 화면 밖으로 넘치지 않습니다.

## 16. 바이브 코딩용 핵심 프롬프트

초기 구현 프롬프트:

```text
Vite + React + TypeScript로 초등 3-4학년 사회 수업용 웹앱을 만들어줘. 첫 화면은 OpenStreetMap 기반 경상북도 실제 지도를 중심으로 보여주고, 지도 위에 경주 불국사, 경주 첨성대, 안동 하회마을, 안동 병산서원, 영주 부석사 무량수전, 영주 소수서원, 고령 지산동 고분군 마커를 배치해줘. 각 마커는 버튼이어야 하고, 클릭하면 문화유산 이름, 지역, 유형, 시대, 사진 영역, 3-4학년 수준 설명, 학생 기록 입력칸이 있는 모달이 열리게 해줘. 기록과 탐험 완료 상태는 localStorage에 저장해줘.
```

지도 구현 프롬프트:

```text
Leaflet과 OpenStreetMap 표준 타일을 사용해 경상북도 실제 지도를 표시해줘. GyeongbukMap 컴포넌트는 latitude, longitude 좌표 기반으로 문화유산 마커를 올리고, 지도 아래에 '지도 자료: OpenStreetMap contributors, ODbL 1.0' 출처를 표시해줘. 마커는 클릭하면 앱의 문화유산 정보 모달이 열리게 해줘.
```

학생 추가 핀 프롬프트:

```text
학생이 '내 핀 추가' 버튼을 누르면 문화유산 이름, 시군, 유형, 설명, 가치 문장을 입력하고 지도 위 위치를 선택해 새 마커를 추가할 수 있게 해줘. 추가 핀은 localStorage에 저장하고, 기본 핀과 다른 색상과 아이콘으로 표시해줘. 개인정보를 받지 않도록 학생 이름이나 주소 입력칸은 만들지 마.
```

테스트 프롬프트:

```text
Testing Library와 Vitest로 마커 클릭, 모달 열림, 기록 저장, 탐험 완료 진행률, 필터, 학생 추가 핀 저장을 검증하는 테스트를 작성해줘. 접근성 검증을 위해 마커는 button 역할과 aria-label을 확인하고, 모달 닫기 후 초점이 원래 마커로 돌아오는지도 테스트해줘.
```
